One word, more than one plant.

ἀψίνθιον· γνώριμος ἡ πόα.

“Wormwood: a well-known herb,” says Dioscorides — and moves on. Dictionaries give one answer. The evidence gives several. Pharmakon keeps all of them, each with a probability and an interval, and carries that doubt into every result downstream.

    Use it from your own tools

    The same data behind this page is open to AI assistants, scripts and notebooks. Everything is read-only and every reply carries the research-only notice and toxicity flags.

    Ask an AI assistant

    Connect the Pharmakon MCP server to Claude, Cursor or any MCP client, then ask things like “which ancient plants were used for burns?”.

    claude mcp add --transport http pharmakon https://pharmakon.adoranto737.workers.dev/mcp

    Tools: search_ancient_names, get_ancient_name, list_leads, get_lead, list_conditions, get_results.

    Call the JSON API

    Plain HTTPS, no key, CORS open.

    curl "https://pharmakon.adoranto737.workers.dev/api/leads?condition=burn&limit=5"
    • /api/names?q= and /api/names/{id}
    • /api/leads and /api/leads/{rank}
    • /api/conditions and /api/results?section=

    Run the pipeline

    Every number on this page is rebuilt from open sources by one command. The research dashboard runs offline on the committed tables.

    git clone https://github.com/LSUDOKO/Pharmakon
cd Pharmakon && make setup test app

      Read before you cite

      • The gold standard is expert judgement, not ground truth.
      • “Support” means PubMed co-mention; the human label audit is still pending.
      • Language models helped read the Greek and plant descriptions. Every quote they produced is checked word-for-word against the source, and none of it feeds the time-travel test.
      • Paul of Aegina is not yet included. All body systems are covered; the Mount Pelion study only records skin uses.
