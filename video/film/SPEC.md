# Pharmakon pitch film — shared spec for every scene author

**The master brief is `../../docs/video/VIDEO_PROMPT.md`. Follow it exactly (story, brand, torn-paper language, motion language, real proof, honesty rules). This spec only splits it into scene files for Remotion.** Film length 8:22; scene lengths and VO line frames come from `src/timing.ts` (regenerated if the VO changes — always read lengths from there, never hard-code a scene length).

Read this, `../../docs/video/VIDEO_PROMPT.md` (the creative brief), `src/brand.tsx` and `src/timing.ts` before writing a scene.

## Ground rules
- Remotion 4.0.541, 1920×1080, 30 fps. Each scene is ONE file `src/scenes/<Name>.tsx` exporting `<Name>`; you only edit your own scene files (plus new files under `src/scenes/<name>/` if you need helpers). Never edit `brand.tsx`, `timing.ts`, `Film.tsx`, `Root.tsx`.
- Wrap the scene in `<Stage>` (black, glow, grain, vignette). Use ONLY brand colours `C.*`, fonts `OUTFIT` / `DIDOT` (all Greek) / `MONO` (numbers, code, labels), the `CHROME` gradient for the wordmark. No other colours, no default fonts.
- Animate with `useCurrentFrame()` + `interpolate`/`ease()` (brand ease `EXPO` = cubic-bezier(.16,1,.3,1)); no CSS transitions/animations, no `Math.random` (seed by index), no `Date`.
- **Sync to the voice:** `scene("<id>").lines[i].from` is the frame (relative to the scene) where VO line i starts; `.dur` its length. Land each visual on the line that names it. The VO is the clock.
- Text on screen: headlines 72–160 px, max ~6 words; the narrator is not repeated word for word on screen. Body text rare (≥ 28 px). Safe margin 120 px (`SAFE`). Bottom 200 px is reserved for burned-in captions: keep key content above y = 860.
- Motion language: word reveals (`<Words>`), count-ups (`<CountUp>`), probability bars that grow then draw whiskers, things that build one part per spoken beat. Continuous subtle drift (1–2 px/s or scale 1→1.02) so no frame is frozen. One focal point per frame.
- Torn-paper identity: `<TornSheet which="a"|"b" img="media/folio-*.webp">` reuses the site's masks; use it as set dressing where it helps. (The scene-to-scene torn-paper wipes are added in `Film.tsx` — don't add your own cut transitions at scene edges; start your first frame on an already-composed background.)
- Every number must come from `public/data/*.json` (copies of `reports/stages/*.json` and `web/public/data`) — load with `staticFile()` + `fetch` inside `delayRender`/`continueRender`, or import the JSON directly (`import r from "../../public/data/identify.json"` works with resolveJsonModule — check tsconfig) — or be hard-coded ONLY if it matches those files exactly. Never invent a number.
- Real images: `public/media/folio-*.webp` (Vienna Dioscorides, public domain), `public/shots/*.jpg` (real site screenshots), `public/shots/chart-*.svg`, plant photos via the Wikimedia URLs in `public/data/dmm-2-169.json` / `dmm-3-23.json` / `leads.json` (`image.thumb`, change `width=` to 800; use `<Img>` with remote URL). Credit images in small mono type when shown full-size.
- Show "Research hypotheses only — not medical advice" where results or leads appear.
- Preview: Studio runs at http://localhost:3123 — composition `scene-<id>`. Before finishing, render 4–6 stills of your scene and LOOK at them: `npx remotion still scene-<id> out/<id>-<frame>.png --frame=<n>`; fix overlaps, overflow, unreadable text, empty frames. Run `npx tsc --noEmit` — zero errors.
